This repository contains the backend code for the Image Gallery project.

### Some of the core features of Image Gallery project:
  - Authentication (Login/Register)
  - Uploading new image
  - Listing all images uploaded by user
  - Creating albums to organize images
  - Adding images to albums
  - Listing all images in an Album
  - Marking images as Favorite
  - Listing Favorite images
  
### Tech Stack and libraries used:
  - NodeJs/ExpressJs
  - Mongoose (for data modelling)
  - Supabase (for storage)
  - JWT (for authentication)
  
### Setting up locally
  - Clone the repository using command `git clone https://github.com/rprakash262/image-gallery-backend.git`.
  - Install the dependencies using command `npm install`.
  - Create a .env file in the project root. Enter all the environment variables based on .env.example file.
  - Start the application using command `npm run dev`.
